# Guía de Marca y UX Operativa (skills_marca)

Esta skill define los lineamientos visuales y funcionales para asegurar que la aplicación sea intuitiva para voluntarios y cumpla con su propósito logístico:

## Paleta Cromática Funcional (Sistema Semáforo)

- 🔴 **Rojo Urgente (`#E53E3E`)**: Vencimiento menor a 48 horas (Prioridad absoluta de salida).
- 🟡 **Amarillo Precaución (`#D69E2E`)**: Vencimiento entre 3 y 7 días.
- 🟢 **Verde Seguro (`#38A169`)**: Larga duración o no perecederos.

## Tipografía y Legibilidad Operativa
Uso de fuentes sans-serif de alto contraste y tamaño adaptado para entornos de almacén con iluminación variable o manipulación rápida mediante dispositivos móviles económicos.

## Iconografía y UX Inclusiva
Elementos visuales universales (cajas, flechas de rotación) diseñados para minimizar la fricción en voluntarios de cualquier edad o nivel de alfabetización digital.
